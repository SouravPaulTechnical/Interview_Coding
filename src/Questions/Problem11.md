## 🧩 Problem: Group Anagrams

Difficulty: Medium Topics: `String`, `HashMap`, `ArrayList`, Collections

Given an array of strings, group together all strings that are anagrams of each other.

Two strings are anagrams if they contain the same characters with the same frequencies, but possibly in a different order.

### Examples

Example 1

```
Input: ["eat", "tea", "tan", "ate", "nat", "bat"]

Output: [["eat", "tea", "ate"],
         ["tan", "nat"],
         ["bat"]]
```

Example 2

```
Input: ["abc", "bca", "cab", "xyz"]

Output: [["abc", "bca", "cab"],
         ["xyz"]]
```

### Requirements

- Use a `HashMap`.
- Don't use Java Streams.
- Preserve every input string in exactly one group.
- The order of groups in the output doesn't matter.
