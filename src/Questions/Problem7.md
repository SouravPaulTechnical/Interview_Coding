### Problem: Swap Two Strings Without Using a Third Variable

Write a Java program to **swap the values of two String variables without using a third/temporary variable**.

The program should:
- Initialize two String variables.
- Display their values before swapping.
- Swap their values using String operations such as `concat()` and `substring()`.
- Display their values after swapping.

### Example

**Input:**
```text
a = "hello"
b = "world"
```

**Expected Output:**
```text
Before swapping:
a = hello
b = world

After swapping:
a = world
b = hello
```

**Constraint:**  
Do not use a third variable such as `temp` to perform the swap.
