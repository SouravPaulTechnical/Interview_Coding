Problem 6: Longest Substring Without Repeating Characters

Given a string, find the length of the longest substring containing no repeated characters.

Example:

Input:
"abcabcbb"


Output:
3

Because the longest substring without repeating characters is:

"abc"

Another example:

Input:
"bbbbb"


Output:
1

And:

Input:
"pwwkew"


Output:
3

because "wke" is the longest substring without repeated characters.
